# gm_resume_flatgrass: Adrian Gomez's Interactive Resume

An explorable, sandbox-style browser game that turns my resume into a 3D world.
Each job and school is a building on the map. Walk up to one and press **E** to read what I did there.

**Play it:** https://YOUR-USERNAME.github.io/adventure-resume/

## Features
- **First-person view** using a raycasting engine written from scratch
- **Third-person top-down view** (toggle with **V**)
- Garry's Mod–inspired look: concrete flatgrass floor, crates and barrels, a Half-Life 2–style HUD, and a weapon list
- Sprinting, head bob, and mouse-look
- Spawn menu for fast travel and a skills list
- On-screen buttons for phones and tablets
- A minimap that shows where you are and which way you're facing

## Controls
| Key | Action |
|---|---|
| W A S D | Move |
| Shift | Sprint |
| Arrow keys / mouse | Turn (click the game once for mouse-look) |
| E | Inspect the building you're facing |
| V | Toggle first / third person |
| Q | Spawn menu (fast travel and skills) |
| 1–6 | Switch held item |
| Esc | Close menus / release the mouse |

## Built with
Plain HTML, CSS, and JavaScript using the Canvas 2D API.
There are no libraries, frameworks, or build steps. The whole game is one `index.html` file.

To run it locally, download `index.html` and open it in any modern browser.
